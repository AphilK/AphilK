I build backend services and data pipelines for systems where latency is a requirement rather than a detail. My background is in energy engineering, and that is where the interest came from: turning physical and mathematical models into software that has to keep running on a factory floor.

At CEPEDI I designed the **Digital Shadow** architecture — a Python API (REST and WebSocket, Clean Architecture) that streams telemetry from 20 industrial machines into a 3D discrete-event simulator, sustaining over **288,000 data points per day at sub-second end-to-end latency**. The ingestion path runs from TLS-secured MQTT through Telegraf into InfluxDB, with API consumption and storage kept as independent, decoupled flows.
